# 第一部分：问题来源与数据来源说明

## 1. 问题来源与工程背景

### 1.1 自动驾驶复杂场景下的决策与规划瓶颈
随着高级别智能网联汽车（SAE L3/L4 级）向规模化量产与商业化落地演进，智能车辆面临的核心挑战已经由结构化道路简单跟驰转变为**高动态、强博弈、长尾高危（Corner Cases）复杂交通环境下的行为决策与实时动态避障**。
- **高速公路强交互汇入 (Highway On-Ramp Merging)**：主线高流速与匝道有限加速区交织，要求主车在极短时空窗内与主线多车进行间隙博弈与速度协同；
- **城市无保护复杂路口 (Unprotected Urban Intersections)**：人机混行、遮挡盲区大、轨迹交织，要求决策具备前瞻意图推理与风险评估能力；
- **长尾极端切入与紧急避障 (Cut-In & Emergency Avoidance)**：传统基于简单硬编码规则的状态机难以应对复杂拓扑与动态多目标约束，易导致“规划求解失效”、“急刹频发”或“安全碰撞事故”。

### 1.2 物理实车道路测试的高成本与高风险痛点
- 实车路测面临安全风险不可控、危险极端工况难构造、偶发失效难复现等突出难题；
- 《中国制造2025》及《智能网联汽车技术路线图 2.0》明确要求：**建立基于数字孪生与高保真虚拟仿真的全栈验证测试平台**。数字仿真建模已成为智能网联汽车研发验证环节不可或缺的核心工具。

## 2. 数据来源与真实数据驱动规范

为了确保本仿真系统具备高保真度、真实数据可溯性与学术严谨性，本系统的数据底座涵盖**国际主流自然驾驶数据集**与**标准场景交换格式**：

### 2.1 真实道路高精度自然驾驶数据集
1. **highD 数据集 (German Highway Drone Dataset)**：
   - **数据源获取**：采用高分辨率无人机在德国高速公路俯拍录制（涵盖超过 110,500 辆真实车辆、44,700 公里行驶里程）；
   - **数据特征**：测量定位误差小于 10 cm，包含丰富的自然超车、主线汇入及连续换道博弈数据；
   - **系统应用**：用于标定本仿真系统的 IDM 跟驰参数及微观交通流背景车博弈行为模式。
2. **INTERACTION 数据集 (International Adversarial Driving Dataset)**：
   - **数据源获取**：加州大学伯克利分校等联合发布的跨国强交互驾驶数据集；
   - **数据特征**：包含环岛（Roundabouts）、无信号灯交叉路口、复杂匝道并线等典型非结构化高危交互场景；
   - **系统应用**：为本系统博弈决策模块（Game-Theoretic Decision-Making）提供强交互基准真值与算法评测对比场景。
3. **NGSIM 数据集 (Next Generation Simulation)**：
   - **数据源获取**：美国联邦公路管理局 (FHWA) 收集的 US-101 与 I-80 高速公路高密度拥堵走廊实测数据；
   - **系统应用**：用于大流量高密度交通流重放与极限合流测试。

### 2.2 仿真场景标准化与数字格式
- **ASAM OpenSCENARIO 2.0 / 1.x**：本系统支持标准化 XML 场景描述语言解析，定义场景触发条件、背景车行为逻辑及天气路况；
- **高精地图拓扑 (Lanelet2 / OpenDRIVE)**：提供路网车道几何、曲率拓扑、相邻车道关系及全局引导参考线（Reference Line）的数字化建模。
