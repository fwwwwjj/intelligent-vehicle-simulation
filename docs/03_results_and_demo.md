## 2. 综合量化评价指标体系 (KPI)

大赛评审严格遵循多维度量化评估体系：

### 2.1 安全性指标 (Safety)
- **碰撞率 (Collision Rate, %)**：全时程碰撞发生频度（目标为 0%）；
- **最小碰撞时距 (Min TTC, s)**：$TTC = \frac{d_{rel}}{\Delta v}$，评估碰撞潜在危险裕度；
- **最小障碍物间距 (Min Distance, m)**：车辆包围盒外边缘到障碍物净距离。

### 2.2 乘员舒适性指标 (Comfort)
- **均方根加加速度 (RMS Jerk, $m/s^3$)**：评估加速度变化的平顺性，ISO 2631 标准推荐舒适阈值小于 $1.5 m/s^3$；
- **最大横向加速度 (Max Lateral Accel, $m/s^2$)**：保障抗侧翻与乘员平稳感受（限制在 $2.5 m/s^2$ 以内）。

### 2.3 控制跟踪精度指标 (Tracking Accuracy)
- **平均绝对横向偏差 (MAE Lateral Error, m)**：实际质心轨迹与规划参考轨迹的侧向误差；
- **最大航向角偏差 (Max Heading Error, rad)**。

### 2.4 计算实时性指标 (Real-Time Performance)
- **单步规划求解时延 (Planning Latency, ms)**：控制在 20ms 以内，满足 50Hz 车载控制器硬实时要求。

## 3. 典型实验对比与分析结果

在同一高难度高速汇入场景（SC-01）下，对比传统规则状态机（HFSM）与本系统博弈决策（Game-Theoretic + Lattice）：

| 评测维度 | 传统规则状态机 (HFSM) | 本系统博弈规划决策系统 | 性能提升比例 |
| :--- | :--- | :--- | :--- |
| **汇入成功率** | 82.5% | **99.2%** | **+16.7%** |
| **最小安全距离** | 2.1 m | **4.6 m** | **+119.0%** (更安全) |
| **平均通行耗时** | 12.8 s | **9.4 s** | **-26.6%** (效率更高) |
| **RMS Jerk (舒适度)** | $2.45 m/s^3$ | **$0.86 m/s^3$** | **+64.9%** (更平顺) |
| **平均横向跟踪误差** | 0.18 m | **0.06 m** | **+66.7%** (跟踪更准) |
| **平均计算耗时** | 3.2 ms | **12.5 ms** | 完全满足实时性 (<20ms) |

**分析结论**：传统规则状态机在遇到主线连续密集群车时，频繁出现由于安全裕度不足而“犹豫减速”甚至在匝道末端“刹停死锁”的现象；而本系统基于动态博弈与多目标时空多项式优化，能够主动利用前后车速度差创造安全插入间隙，以高舒适度、零碰撞指标平滑汇入主线。
